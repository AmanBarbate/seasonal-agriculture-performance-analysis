# Seasonal Agriculture Performance Analysis

VOIS AICTE Major Project — analyzing seasonal agricultural performance 
(Kharif, Rabi, Zaid) using a dataset of 4,000 farm records across 8 Indian states.

## Objective
Identify meaningful patterns, trends and differences in agricultural 
performance across seasons using data cleaning, EDA, statistical testing 
and visualization.

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy

## Key Analysis
- Season-wise yield, profit and resource usage comparison
- ANOVA test for statistical significance
- Crop x Season and State x Season heatmaps
- Correlation analysis of environmental & performance variables

## Files
- `Seasonal_Agriculture_Performance_Analysis.ipynb` — full analysis notebook
- `seasonal_agriculture_performance_dataset.csv` — dataset
